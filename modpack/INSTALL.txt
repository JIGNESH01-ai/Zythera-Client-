ZYTHERA CLIENT 1.20.1 — EXPERIMENTAL FABRIC INSTANCE
Made by JIGNESH_GAMING-k7j | Subscribe on YouTube

This is not a launcher APK or a copy of Minecraft. You need a legally owned Minecraft Java account, internet access for Minecraft/Fabric libraries on first launch, a launcher with Java 17 and Minecraft 1.20.1 support, and enough free device storage. Android 9, 3 GB RAM, Pojav Legacy and the bundled mods have not been tested together. A launcher may not expose an import feature at all; steps below describe the Pojav-based launcher in this repository and may differ elsewhere.

IMPORT AS AN INSTANCE (launcher in this repository)
1. Back up your worlds and existing profiles. Download zythera-client-1.20.1-v0.5.7-alpha.mrpack (or the identically structured .zip) to Android Downloads. Do not extract it.
2. Sign in with a Minecraft Java account in the launcher. The source code's profile creation screen requires an online account for modpack imports.
3. On the profile/instance selector, create a new profile (+), select Mod Pack, then select "Import Zip or mrpack". In the Android file picker choose the downloaded .mrpack. If the picker hides it, show all files or use the .zip import archive instead.
4. Wait for the import AND the Fabric Loader download/install to finish. The manifest specifies Minecraft 1.20.1 and Fabric Loader 0.15.11; the mod JARs and config are bundled in overrides. The import code in this repository creates a separate custom_instances directory and a profile named "Zythera Client". Minecraft, assets, libraries and Fabric Loader still need to be downloaded by the launcher.
5. Select the Zythera Client profile. Select an installed Java 17 runtime in the launcher. Set memory conservatively on a 3 GB phone (start around 1024 MB, leaving Android memory free); renderer and actual available RAM differ by phone. Launch once while connected to the internet. Wait for downloads.
6. Open the installed-mods list via Mods on the title or pause screen. Map Right Shift to open Zythera feature settings. Map C to a touch control and hold it to zoom. Minecraft's Accessibility Settings > Sprint: Toggle enables vanilla toggle sprint. Set the optional HTTPS YouTube channel URL in Zythera Mods > Settings.

NO IMPORT BUTTON / IMPORT FAILED
Use zythera-modpack-1.20.1-v0.5.7-alpha.zip instead (NOT the .mrpack-style instance zip). Create a separate Minecraft 1.20.1 Fabric Loader 0.15.11 profile with Java 17 in your launcher, run it once and exit. Extract this manual ZIP to a temporary folder, then copy its mods, config, resourcepacks and options.txt into that profile's game directory. Avoid overwriting existing data; do not place the ZIP itself in mods, and remove older duplicate mods. Follow your launcher's profile editor to locate its game directory. Some Android file managers cannot access Android/data on newer devices; use the launcher's file manager or the system picker. On Android 9 storage permissions/path vary by launcher installation.

TROUBLESHOOTING AND LIMITS
- If the game fails to start with Sodium, remove its JAR from this instance's mods folder and retry with a renderer supported by your Pojav build/device. Zythera and Lithium do not require Sodium. Do not mix old or incompatible copies of Fabric API, Sodium, Lithium or Zythera.
- The included options.txt gives a conservative starting point; use Zythera Mods > FPS Boost > Potato or Minecraft video settings to adjust. The starter options apply only to a newly imported instance; do not copy options.txt over settings you want to keep.
- Built-in HUDs and menu controls are provided by the Zythera mod, not an external mod manager. The optional Zythera-Extras resource pack is a placeholder and does not need enabling. Resource-loading progress is not world-generation progress. Ping is unavailable in singleplayer; CPS counts left mouse presses.
- The desktop development smoke test, if successful in CI, checks the Zythera title and splash render only. It does not validate the packaged mod set, gameplay, accounts, multiplayer, Pojav, Android 9, touch input, or low-memory performance. The pack is an alpha and may fail on your device. Check server rules for zoom/sprint.

The default Potato preset requests 2 render chunks and 2 simulation chunks on first start; change them in Minecraft or Zythera FPS Boost. It is not reapplied on later launches. See COMPATIBILITY.md for third-party optimization selection and limitations.

The Zythera resource-loading overlay intentionally takes at least 19.8 seconds on each resource reload (including F3+T) for its visual startup sequence. Its animation percentage is not Minecraft's real progress; the separate Resources line is. Minecraft can wait longer if its resources are still loading. Reload errors are passed through to Minecraft.
