# 1.20.1 optimization selection

Included: Sodium 0.5.11, Lithium 0.11.4, and FerriteCore 6.0.1 (Fabric; upstream metadata lists 1.20.1 and no additional dependencies). Fabric API and Zythera are included too. The release workflow checks JAR IDs/versions and archive integrity; FerriteCore is SHA-512 pinned to its upstream version metadata. This is not proof of Pojav compatibility. Sodium can fail on mobile renderers; remove it if needed. No claims of benchmarked FPS improvement or reduced heap allocation.

Not bundled: Sodium Extra, ImmediatelyFast, Entity Culling, More Culling, Enhanced Block Entities, Cull Leaves, ModernFix, Dynamic FPS, LazyDFU, Noisium, Krypton, FastQuit, ThreadTweak, Debugify, BadOptimizations, FastChest, FastFurnace, FastWorkbench, and Starlight. Their exact versions, dependencies, renderer interactions and redistribution terms have not all been independently verified for this pack and Android; Entity Culling's published 1.6.7 license contains noncommercial restrictions. Starlight provides limited benefit to modern vanilla lighting and is not needed here. Do not blindly install Forge-only mods in Fabric. This exclusion is a stability/verification decision, not a claim that all of those mods are incompatible with 1.20.1.

Minecraft options are set once on initial Zythera initialization and when the user explicitly selects a preset. The pack supplies a new-profile options.txt as well. Minecraft stores subsequent edits in options.txt; Zythera does not reapply a preset each launch. Profiles do not change mod-specific settings or the JVM heap. Configure RAM in the launcher, not the game. Some renderer- or resource-intensive effects are controlled by Minecraft options; not all animations/effects have a global switch in vanilla 1.20.1.
