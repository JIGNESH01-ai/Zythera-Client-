# Optional performance mods for Minecraft 1.20.1

These are optional third-party downloads, not embedded in the Zythera JAR. Install the **regular** JAR (not the API JAR), alongside Fabric API and Zythera in the 1.20.1 Fabric profile's `mods` directory. Do not combine with another version or duplicate JARs. Verify each mod's license and requirements yourself before redistribution.

| Mod | Verified upstream release | Notes |
| --- | --- | --- |
| Lithium 0.11.4 | [Minecraft 1.20.1 release](https://github.com/CaffeineMC/lithium/releases/tag/mc1.20.1-0.11.4) | Fabric version; general game optimizations. |
| Sodium 0.5.11 | [Minecraft 1.20.1 release](https://github.com/CaffeineMC/sodium/releases/tag/mc1.20.1-0.5.11) | Rendering rewrite. **May not work with your Pojav renderer/device**; try separately and remove if it fails. |

Version labels and release assets were checked against upstream GitHub releases; **the combination has not been tested** on desktop or Pojav. They are not required for Zythera to load. No claims are made for other requested optimization mods. Never install Starlight or other incompatible/obsolete optimizers just because their name appears on a list.
