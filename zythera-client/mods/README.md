# Local 1.20.1 Fabric mod JARs

This directory is a local download destination, **not** the running game's mods folder unless you configure the launcher to use it as its game directory. Mod JARs are ignored by Git. JourneyMap's authors prohibit rehosting its JAR; it must be downloaded directly from Modrinth or CurseForge. The repository cannot provide all requested JARs as a bundled archive.

On a machine with Python 3 and internet access, run `python3 zythera-client/scripts/download-requested-mods.py` from the repository root. The installer downloads the pinned JARs directly from their publishers' Modrinth pages and Aetherium's GitHub release, verifies checksums and Fabric metadata, and refuses to use a folder already containing JARs. For an existing launcher instance, download into a separate empty directory, back up the instance, then review and copy the JARs into that instance's `mods` folder. Do not keep duplicate versions. You must also install the Zythera JAR from the release and Fabric Loader 0.16.14 or newer separately.

**Experimental:** these selections have not yet been verified together on Android/Pojav or for gameplay. They are not the 0.5.6 packaged modpack. Aetherium's publisher says not to combine it with Sodium; remove Sodium from a copy of the instance before adding Aetherium. Zoomify requires Fabric Language Kotlin and YACL; both are downloaded. Zythera also has built-in zoom; disable it or unbind a zoom key to avoid conflicts. Clumps and chunk pregeneration affect the integrated server / server worlds; pre-generation can heavily load low-end devices. Do not rehost or redistribute restricted JARs.
